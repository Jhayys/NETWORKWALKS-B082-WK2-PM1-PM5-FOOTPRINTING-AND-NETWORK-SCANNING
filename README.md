

# NETWORKWALKS B082 – WEEK 2
## Footprinting, Reconnaissance and Network Scanning

### Project Overview
This repository documents my Week 2 practical cybersecurity projects completed as part of the NetworkWalks B082 Cybersecurity Training Programme.

The practical work covers footprinting and reconnaissance using multiple Kali Linux tools, alongside network scanning and topology mapping using Zenmap.

### Projects Completed

**W2-PM1: Footprinting and Reconnaissance with Multiple Kali Tools**

Tools used:
- WHOIS
- WhatWeb
- Nslookup
- cURL
- WAFW00F
- DNSRecon

Activities included domain registration information gathering, DNS enumeration, web technology identification, HTTP header inspection and WAF detection.

**W2-PM5: Zenmap Network Scanning**

Activities included:
- Identifying the local IP address and network subnet.
- Checking the default gateway and connectivity.
- Discovering live hosts on the local network.
- Recording available IP and MAC addresses.
- Performing a Zenmap Ping Scan.
- Generating and exporting a network topology.
- Saving scan results in XML format.

### Tools and Environment
- Kali Linux
- Zenmap
- Nmap
- WHOIS
- WhatWeb
- Nslookup
- cURL
- WAFW00F
- DNSRecon

### Key Findings

- Identified domain registration and DNS information.
- Identified web technologies and HTTP response headers.
- Detected a Web Application Firewall response.
- Discovered three live hosts on the local lab network.
- Identified the local gateway, Kali Linux VM and another live host.
- Generated a network topology and saved scan results.

### Challenges and Troubleshooting
The PM5 guide referenced a Windows environment. Since I worked on a MacBook M1 using Kali Linux, I completed the Zenmap practical within my Kali Linux virtual machine.

I also encountered a topology display readability issue and checked the exported PDF to confirm that its contents were readable.
